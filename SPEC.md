# ТЗ: Playable Viewer (статическая версия)

## 1. Назначение
Статический сайт для просмотра playable-креативов (self-contained HTML).
Одна страница: список с иконками + превью в рамке телефона. Бэкенда нет.
Контент добавляется вручную: файлы кладутся в проект, запись — в `playables.json`.

## 2. Стек
| Слой | Технология |
|---|---|
| Фронтенд | Vue 3 (`<script setup>`) + TypeScript + Vite |
| Данные | `playables.json` в корне (импорт на этапе сборки) |
| Хостинг | Любой статик-хостинг (Vercel / GitHub Pages / Netlify) |

Без бэкенда, авторизации, роутера и Pinia — намеренно упрощено.

## 3. Данные

**`playables.json`** в корне проекта — массив объектов:
```json
[
  { "id": "tap-blast", "name": "Tap Blast",
    "html": "/playables/tap-blast.html", "icon": "/playables/tap-blast.svg" }
]
```
| Поле | Описание |
|---|---|
| `id` | уникальный идентификатор |
| `name` | отображаемое название |
| `html` | URL html-файла от корня сайта |
| `icon` | URL иконки (рекомендуется 256×256) |

**Файлы** (html + иконки) лежат в `public/playables/` и отдаются как статика.
Пути в JSON — это URL от корня сайта (например `/playables/foo.html`).

## 4. Страница
- **Десктоп (> 720px):** слева список карточек (иконка + имя), справа рамка
  телефона с `<iframe>`, играющим выбранный плейбл. Выбор устройства,
  переключатель ориентации, кнопка «Перезапустить».
- **Мобильный (≤ 720px):** список карточек; тап открывает html в новой вкладке.

iframe: `sandbox="allow-scripts allow-same-origin allow-pointer-lock allow-popups"`.

## 5. Как добавить плейбл
1. Положить `<name>.html` и иконку в `public/playables/`.
2. Добавить объект в `playables.json`.
3. Закоммитить и запушить (хостинг пересоберёт автоматически).

## 6. Ограничения
- Playable должен быть self-contained (ассеты в base64 внутри html).
- Размер репозитория растёт вместе с файлами — следим за объёмом сами.
