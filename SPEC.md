# ТЗ: Playable Viewer

## 1. Назначение
Веб-приложение для хранения и онлайн-просмотра playable-креативов (self-contained HTML).
Просмотр — публичный по ссылке. Добавление/удаление — только для админа.

## 2. Стек
| Слой | Технология |
|---|---|
| Фронтенд | Vue 3 (`<script setup>`) + TypeScript + Vite |
| Стейт | Pinia |
| Роутинг | Vue Router |
| Бэкенд (BaaS) | Supabase: Auth + Postgres + Storage |
| Деплой | Vercel (автодеплой из GitHub) |

## 3. Модель данных

**Postgres, таблица `playables`:**
| Поле | Тип | Описание |
|---|---|---|
| `id` | uuid (PK) | генерируется |
| `name` | text | имя, задаётся при загрузке |
| `storage_path` | text | путь в бакете, напр. `{id}.html` |
| `file_size` | int8 | размер в байтах (для счётчика места) |
| `created_at` | timestamptz | дата загрузки |

**Storage:** бакет `playables`, публичный на чтение. Файлы `{id}.html`, content-type `text/html`.

**RLS:**
- `SELECT` — публично.
- `INSERT` / `DELETE` — только аутентифицированному админу.
- Аналогично на бакете Storage.

> `anon key` в Supabase публичный по дизайну — он попадает в собранный фронтенд, это нормально.
> Защиту от чужой записи обеспечивает RLS, а не сокрытие ключа. Публичная регистрация в Auth отключена — существует только админ-аккаунт.

## 4. Авторизация
- Один админ, Supabase Auth (email + пароль). Аккаунт заводится вручную в панели Supabase.
- Кнопка «Войти» в шапке. После входа доступен `/admin`.
- Роуты админа защищены на клиенте (guard роутера) и на сервере (RLS).

## 5. Страницы и роуты
| Роут | Доступ | Описание |
|---|---|---|
| `/` | публично | Главная: слева список, справа рамка телефона с плейблом |
| `/play/:id` | публично | Плейбл на всю страницу (для мобильных) |
| `/login` | публично | Форма входа админа |
| `/admin` | админ | Загрузка, удаление, счётчик места |

## 6. Функциональность

**Просмотр (десктоп):**
- Слева список плейблов (имя, дата).
- Справа рамка телефона с `<iframe sandbox="allow-scripts allow-same-origin">`.
- Выбор устройства (пресеты) + переключатель ориентации портрет/ландшафт.
- Кнопка «Перезапустить» (пересоздаёт iframe).

**Мобильная версия (узкий экран):**
- Только текстовый список. Тап → `/play/:id` во весь экран.

**Админка (`/admin`):**
- Форма: `.html` файл + имя → загрузка в Storage + запись в таблицу.
- Список с удалением (файл + запись).
- Счётчик места: сумма `file_size` / 1024 МБ, прогресс-бар.

## 7. Регистрации
1. **GitHub** — репозиторий.
2. **Supabase** — проект, бакет, таблица, админ-аккаунт. Взять `Project URL` и `anon key`.
3. **Vercel** — подключить репозиторий, env-переменные, автодеплой.

Env: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`.

## 8. Ограничения
- Free tier Supabase: проект засыпает после ~7 дней без активности.
- Лимиты free: 500 МБ БД, 1 ГБ Storage (отслеживаем счётчиком).
- Playable должен быть self-contained (ассеты в base64).
